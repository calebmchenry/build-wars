# Guide Authoring

## Goal

Let users write practical build guides with embedded builds, variants, equipment, skill links, usage notes, counters, and synergy.

## Scope

* Markdown or lightweight rich-text authoring.
* Skill links and inline skill icons.
* Embedded skill bars and equipment sections.
* Variant sections with optional slots.
* Guide metadata for mode, role, rating/status, source, and freshness.
* Preview mode.

## Done When

* A user can write and save a guide for a build.
* Skill links and build embeds render consistently.
* Guide data can be exported and restored.

## Notes

PvX-style guides are content-rich, but full PvX import should be separate from first guide authoring.
