# Title Tracks and PvE-only

## Goal

Catalog PvE-only skill rules, title-rank scaling, allegiance restrictions, and title-based effects.

## Scope

* PvE-only skill list.
* Three-PvE-only-skill bar limit.
* Title tracks used by skills.
* Effective title-rank scaling rules.
* Kurzick/Luxon allegiance exclusivity.
* Lightbringer, Sunspear, Asura, Deldrimor, Ebon Vanguard, Norn, Kurzick, and Luxon coverage.
* Anniversary and special PvE-only edge cases.

## Done When

* PvE-only skill validation works.
* Title skills can render scaled descriptions.
* Skill filters can distinguish PvE-only, title, common, and profession-linked skills.

## Notes

This overlaps with skills but deserves its own epic because title scaling is not the same as ordinary attribute scaling.
