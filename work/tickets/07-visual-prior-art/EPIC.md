# Visual Prior Art

## Goal

Organize screenshots and extract reusable UI/aesthetic notes for in-game-inspired rendering.

## Scope

* Inventory all screenshots under `prior-art/`.
* Group references by skills panel, skill tooltip, template dialogs, equipment panel, weapon sets, party selector, and PvX guide display.
* Record typography, colors, borders, spacing, icon treatment, selected states, disabled states, and tooltip behavior.
* Identify remaining screenshot gaps.
* Keep notes factual and tied to screenshot file paths.

## Done When

* UI implementation tickets can cite specific screenshots.
* The app has a clear aesthetic target.
* Remaining screenshot gaps are explicit and small.

## Notes

Current coverage is strong for MVP. Remaining useful captures are standalone rune/insignia/weapon-upgrade item tooltips and full party window references.
