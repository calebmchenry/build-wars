# Party and Hero Builder

## Goal

Support party compositions built from player, hero, mercenary, and optional team-member slots.

## Scope

* Party builder for solo, player plus heroes, mercenary heroes, and larger team formats.
* Per-slot role labels, profession pair, skill bar, equipment, and notes.
* Hero-specific metadata and portraits.
* Preferred skill ordering and hero AI notes.
* Copy/export all party skill templates.
* Optional paw-ned2 team build compatibility.

## Done When

* A user can assemble and save a practical hero team.
* Party slots can reference or duplicate existing builds.
* Team export preserves slot names, roles, and codes.

## Notes

Support up to 12 slots for compatibility with existing tools, even if most use cases are 4 or 8 member parties.
