# Build Wars

[Open Build Wars](https://calebmchenry.github.io/build-wars/)

Build Wars is a local-first TypeScript web app for composing, validating, importing, exporting, and
sharing Guild Wars 1/Reforged builds.

## GW1 Build Community

- [GW1 Builds](https://www.gw1builds.com)
- [Guild Wars Wiki](https://wiki.guildwars.com)
